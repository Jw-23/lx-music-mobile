# Android TV 与遥控器

从 v1.10.12 开始，应用包含 Android TV / Google TV 电视桌面入口。电视自动使用横向侧栏，内容四周预留安全边距。安卓盒子未自动识别时，在“设置 → 基本设置”开启“电视遥控模式”。电视系统识别出的设备会始终开启此模式。

安装时不确定盒子的 CPU 架构，可选择发布页中的 `universal.apk`；它包含 32 位与 64 位架构。电视模式与手机版使用同一个应用、资料库和设置。

| 遥控器操作 | 行为 |
| --- | --- |
| 方向键 | 移动白色焦点框；列表随原生焦点滚动 |
| 确认 / OK / Enter | 激活当前按钮，或进入输入框并使用系统软键盘 |
| 返回 | 关闭面板或返回上一层；队列调整中先结束调整 |
| 播放 / 暂停 | 对应播放或暂停；播放暂停组合键切换状态 |
| 上一曲 / 下一曲 | 切换歌曲 |
| 快退 / 快进 | 后退或前进 10 秒，限制在歌曲有效范围内 |
| 音量 | 交由系统控制 |

## 播放与队列

只有方向键的遥控器也可操作播放栏中的上一曲、播放/暂停、下一曲及队列图标。完整播放页另有后退/前进 10 秒按钮。

打开队列后，移动焦点到歌曲右侧的三线手柄，按确认进入调整状态，焦点框变为橙色。上下移动歌曲，完成后再次按确认；返回键也可结束调整。稍后播放和普通队列分别排序，队列与实际播放保持同步。移动的是本次播放顺序，原歌单保持不变。触屏仍使用拖动。

## 适配实现与验证范围

本项目保持现有 React Native 0.73 Android 依赖，通过原生焦点作用域支持方向键，并在原生窗口上绘制焦点框。电视主页面不挂载手势翻页容器；缓存页面、被详情遮挡的页面和退出中的面板阻止子控件获得焦点。返回详情时尝试恢复原控件，弹窗优先选择内容控件而非全屏遮罩。

媒体按键共用播放器入口，在未取消的按键松开事件执行，避免一次按键触发多次。队列调整使用同一套无障碍调整动作，并在没有开启读屏服务时初始化动作映射。禁用控件不参与焦点导航。

自动化覆盖设备和手动模式、媒体键策略、播放调用、进度边界、队列标识稳定性、缓存页面隔离及弹窗退出焦点；另外执行 TypeScript、lint 与 Android Java 编译。当前没有连接实体电视进行遥控器测试；各品牌软键盘、焦点滚动和播放页布局仍需在实际电视上验证。

实现参考 Android 官方的[电视应用配置](https://developer.android.com/training/tv/get-started/create)与[遥控器导航说明](https://developer.android.com/training/tv/get-started/navigation)。
