# 声音与响度

Android 手机、TV 与手机控制网页共用 `player.volume`（0–1）和 `player.loudnessNormalize`（默认 true）。设置即时保存并应用，不修改系统媒体音量。

进入播放页的扬声器图标，或设置 → 播放 → 声音控制。手机支持滑动调节；TV 支持遥控器确认静音、恢复和 ±5% 控制。

播放器在 PCM 解码后、用户音量前进行 RMS 均衡，400ms 测量块、约 8 秒能量平滑，目标 -18dBFS RMS；增益限制为约 ±12dB。低于 -50dBFS 的测量块不提高目标增益。左右声道共用增益，按帧限制样本峰值到 -0.5dBFS，避免通道位置漂移和数字削波。增益下降约 120ms、上升约 3 秒，限幅释放约 150ms。

这是实时均衡，不是预分析整首歌的 LUFS 母带处理，也不保证不同动态歌曲或不同设备产生完全一样的主观响度。开始、跳转后的几秒钟会重新分析。开关可随时关闭。

为确保该软件处理链工作，播放器关闭编码直通和硬件卸载。原设置值保留，但当前构建不使用；关闭均衡仍通过同一 PCM 链路，以便即时重新开启。

`android/audio.gradle` 在构建目录生成播放器 Java 源码并接入受版本控制的音频处理器，不修改 node_modules。上游 Media3 版本为 1.8.0。

v1.10.15 按用户要求跳过单元测试、类型检查、lint 和实机验证，仅由 Actions 编译与发布；后续版本恢复原验证步骤。
