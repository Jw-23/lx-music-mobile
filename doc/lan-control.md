# 局域网手机控制

从 v1.10.13 开始，Android 应用内置控制网页。电视自动开启，普通手机需要在基本设置的“手机控制”中开启。手机与电视连接同一网络，应用运行时在手机浏览器打开电视上显示的网址，如 `http://192.168.1.192:9528`。网页和接口都由电视提供，电脑可以关闭。

## 配对与退出

电视右上角手机图标或“设置 → 基本设置 → 手机控制”显示当前网址和六位配对码。输入配对码后，手机可以操作设置、音源与播放。配对连接在当前浏览器标签页保存，最长八小时；服务重启、更换配对码会使旧连接失效。网页的“断开”只撤销当前手机；电视中的“更换配对码”撤销所有手机。也可直接关闭局域网控制开关。

## 支持的操作

- 设置：启动播放、启动进入播放页、播放栏、返回/退出按钮、播放模式、音质、歌词翻译/音译/对齐/字号、列表信息和搜索偏好。
- 音源：选择手机上的 JS 文件（最大 4 MB）或填写 HTTP/HTTPS 下载链接。导入保存到电视，不会自动运行；点击“使用此源”才开始初始化。失败时保留输入，可重试。只导入你信任的源。
- 搜索：选择音乐平台、搜索歌名或歌手、翻页，点击结果右侧播放按钮在电视点播。结果在电视端保存十分钟，过期后重新搜索。搜索不会切走电视当前页面。
- 播放：查看状态、播放/暂停、上一首、下一首、后退/前进十秒。点播与电视端搜索播放使用同一资料库和播放器。

## 连接条件

服务端口固定为 9528，支持 IPv4 局域网，通过 Wi-Fi 或以太网均可连接。需保持电视上的应用运行；电视被断电或系统回收应用时网页会提示无法连接。路由器的访客网络、设备隔离或电视端防火墙可能阻止同网设备互访，遇到连接失败可先确认电视显示的网址。

服务使用本地 HTTP，仅接受局域网客户端、当前本机 IP 的 Host 和同源 Origin。接口需要配对令牌，配对失败限流，令牌与配对码不会放入网址或公开网页。网页不加载第三方脚本，音源说明和搜索文字以文本显示。无需配置路由器端口转发。

## 开发与验证

原生 `LanHttpServer` 使用 Android 6.0 已支持的 ServerSocket 与 CountDownLatch，不新增 Android 依赖。三个静态资源随 APK 打包；原生 HTTP 工作线程通过带截止时间的事件调用应用命令，应用初始化完成后才接受操作。关闭服务会停止监听、关闭连接并清理等待请求。

常用设置使用白名单和值校验，修改走现有设置入口。导入沿用现有持久化队列；修改和导入顺序执行，排队过期的命令不再修改应用。搜索最多并行两个，每个平台直接调用现有 SDK 并使用 `toNewMusicInfo` 转换；浏览器只接收显示字段，播放信息保存在电视端，点播只接受对应结果标识与索引。

自动化包含真实回环 HTTP 测试（配对、认证、来源与 Host 校验、错误长度、重复请求头、大小限制、退出与端口释放）、命令校验、存储和下载失败、操作排队过期，以及真实应用桥接的搜索转换与点播。

原生 API 参考：[ServerSocket](https://developer.android.com/reference/java/net/ServerSocket)、[CountDownLatch](https://developer.android.com/reference/java/util/concurrent/CountDownLatch)。
